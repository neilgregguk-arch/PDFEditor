# Authentic original Word corpus

Five PDFs exported directly by local Microsoft Word using tools/create_original_word.ps1. No positive was first edited or normalised through PDFEditor. Matching DOCX and provenance files are retained. Personal author properties were removed before export; DOCX creators are blank. Text is fictional test material.

Cafe/letter: supported two-row originals. Calm/original-multiline: retained exact-row bitmap failures. Separate-paragraphs: nearby identical-style independent paragraphs, never merge. Each PDF's producer, actual embedded fonts, characters and structure were inspected; evidence/original-tests.json records hashes/classifications.

Actual embedded font is bundled renamed Prototype Sans, derived from Bitstream Vera, with no proprietary fallback. LICENSE.txt reproduces the existing font permission/notice. fsType=4 is recorded; the licence grants distribution/modification subject to its notice/naming conditions. No new proprietary font/document asset is introduced. This fixture-specific review does not settle the whole repository licence or inherited corpus rights.
