# Phase 5.2.1 open issues

- The original screenshot images and paste mode remain unavailable. The complete supplied clarification brief was tested in replacement/append modes, alongside controlled shorter/longer cases. The user's original physical workflow still needs retesting.
- Amber text is a retained, scrollable correction surface. Its native wrapping is not approved PDF geometry. A long draft can remain unsaveable after this presentation correction; available space, font size, ownership and neighbour positions are not expanded.
- The historical intermittent clipboard Win32 5 issue remains open. One intermediate run passed clipboard; shipping regression reproduced the failure. Shared paste processing and routed character input are tested separately; no clipboard fix is claimed.
- Programmatic WPF controls, native hit testing, routed commands and four app zooms do not certify physical mouse/keyboard/clipboard behaviour, native file dialogs, OS display scales, IME, screen readers, high contrast or general accessibility. Retest selection/scrolling on the user's desktop.
- Very narrow or shallow source areas remain constrained reading/editing surfaces; they do not grant permission to cover neighbouring graphics. General document reflow and arbitrary alternative editing areas are outside scope.
- Existing unsupported font/glyph, hard-newline, repeated-space/extraction, mixed-style/structure and original discovery restrictions remain. Two Phase 5.2 original Word examples still fail exact bitmap reconstruction. Core is unchanged.
- Character-by-character undo, inherited resource/timeout limits, broader native/parser/font security review and repository-wide/inherited-font licensing review remain open. No broad memory refactor, licensing resolution or accessibility certification is claimed.
- Recovery is isolated under the new phase5_2_1 store. Earlier stores remain untouched and are not automatically migrated. Source identity/revision guards remain authoritative; incompatible source recovery is never silently applied.

Stop after Phase 5.2.1. Phase 5.3 requires separate review and user acceptance.
