| Input / behaviour | Phase 5.1 | Phase 5.2 |
|---|---|---|
| Fresh original Word cafe, two rows | Separate Limited/eligible rows | One structurally verified editable group |
| Fresh original Word letter, two rows | Separate rows | One group and genuine verified export |
| Fresh calm / longer multiline originals | Exact-row reconstruction failures | Still restricted; files not rewritten to pass |
| Fresh short separate Word paragraphs | Separate regions | Never merged |
| Original click either row / cross-row replacement | No complete original-group session | Complete logical session and exact offsets |
| Original first -> second -> third save | Original grouping unavailable | First declaration, then validated marked rediscovery |
| Existing Phase 5.1 marked groups | Whole-group editing | Retained: 37 worker and 16 WPF checks |
| Original + marked + natural + another-page edit | Original group unavailable | Four drafts/history/recovery/atomic export |
| Same font/proximity without supported structure | Conservative legacy classifications | No new geometry-only ownership |
| Swapped/duplicate ParentTree index/backlink | No original-group mechanism | Original grouping refused |
| Heading/table/list/header/footer / different scope | Restricted or independent regions | Not merged into a new original paragraph |
| Columns/labels/interleaving/graphics | Restricted | Retained/new explicit refusals |
| Rotated/clipped/mixed-size/style rows | Restricted | Structure cannot override guards |
| Ambiguous/missing source row space | No original grouping | No invented separator; refused |
| Separate terminal nonpainting F2 space | Protected | Still protected, never owned; narrow same-scope coexistence |
| Unsupported raw proof syntax / xref-stream-only | No original grouping | Original expansion refused; valid 5.1 declarations retain their validator |
| Natural paragraphs / supported single rows | Supported | Retained |
| Unsupported glyphs/hard breaks/unsafe growth | Draft retained, export blocked | Retained |
| Adjacent spaces failing exact extraction | Blocked | Still blocked; exact draft/recovery retained |
| Clipboard Win32 5 | Open intermittent issue | Reproduced current and untouched 5.1; not fixed |

Fresh acceptance uses genuine original Word exports under run/original-paragraphs with fictional authored text, actual font/structure inspection, provenance/hashes and attached open-font notice. Derived adversarial/mixed fixtures are labelled separately. Support remains bounded ASCII/original-font editing, not universal Word paragraph recovery or accessibility certification.
