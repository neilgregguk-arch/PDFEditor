## Implementation

- `Core/OriginalParagraphs.cs` runs after strict Phase 5.1 declaration validation and before inherited ambiguity/space checks. It requires native Document/P/single-MCID evidence, matching raw indexed proof, shared actual Span handles, complete ordered contiguous members, explicit separators and compatible original font/style/geometry. Refusal leaves machine-readable reasons and observed diagnostics.
- `Core/OriginalStructureProof.cs` independently checks the indexed structural association which the public native tree API does not expose. Its narrow reader follows actual xref entries, Word hybrid Flate xref/object streams, page-tree backlinks, StructParents, ParentTree, Document/P backlinks, K/MCID and Pg. It does not interpret text operators, font mappings or rendering. Native and raw evidence must agree; unsupported syntax refuses compatibility expansion.
- `Core/Discovery.cs` supplies the immutable source filename, integrates grouping and records cost. Nonpainting separately retained whitespace avoids the vertical boundary cap only when it shares the paragraph's actual semantic scope. Foreign/next-paragraph whitespace remains a boundary. Whitespace is never absorbed into ownership.
- `Core/ParagraphMarks.cs` allocates a fresh private ID for an independently qualified original's first export. Existing validated declarations retain their ID. Schema, payload/member validation and security bounds remain intact.
- `Core/DocumentTransaction.cs` passes the correct filename for source and saved-candidate discovery. Existing all-draft identity resolution, collision checks, source-position insertion, original-font runs, owned-member removal, semantic transfer, candidate reopen and atomic new-file save remain.
- `App/ParagraphControlTests.cs`, `Checks/Program.cs` and new Python tools cover original-row interaction, three generations, four-region exited-process recovery, model invariants, adversaries and resource measurements. Existing proposed-position ink/caret/selection is reused.

Actual `PositionedLine` observations preserve every source baseline, glyph origin/box and logical start. Existing temporary flattening is only an alignment copy. It never replaces source observations, and surviving-pair exceptions cannot cross actual source rows. Unchanged presentation retains Word's observed leading; edited wrapping uses the established conservative 24pt leading for these 12pt fixtures and refuses growth into the next protected paragraph. Neighbours are never moved.
